# Code Change Preferences

## When suggesting code changes:
- Always show code changes with **color-coded markers** to clearly indicate what was changed
- Use visual indicators:
  - 🟢 Green = New additions or changes
  - 🔴 Red = Deletions or remove operations
  - ➕ Added content
  - 🔄 Modified content
  - ✅ Kept/unchanged content
- Clearly mark which lines were changed, added, or removed
- Show BEFORE and AFTER when making significant changes
